# Computer Networks Lab Programs

This set follows the ten experiments in the supplied Computer Networks lab manual. The manual’s NS2 topologies and traffic examples are retained; incomplete input handling and obvious source errors were corrected. Each experiment has its own folder.

The repository already had five top-level source files. They are preserved unchanged; the folders below provide the organized versions for this ten-experiment set.

## Experiments and files

| Experiment | Topic | Files | Language |
|---|---|---|---|
| 01 | Three-node point-to-point links, queue limits, bandwidth and packet drops | `prog1.tcl` | NS2 Tcl |
| 02 | Six-node ping and traceroute-style hop probes under congestion | `ping_traceroute.tcl` | NS2 Tcl |
| 03 | Ethernet LAN with two TCP congestion windows | `ethernet_lan.tcl`, `cwnd.awk` | NS2 Tcl, AWK |
| 04 | CRC-CCITT, 16-bit | `CRC1.java` | Java |
| 05 | Sliding-window frame transmission | `SlidingWindow.c` | C |
| 06 | Bellman-Ford routing with full path vectors | `ford.java` | Java |
| 07 | TCP client-server text file transfer | `server1.java`, `client1.java` | Java |
| 08 | UDP datagram request and uppercase reply | `UDPServer.java`, `UDPClient.java` | Java |
| 09 | RSA encryption and decryption demonstration | `RSA.java` | Java |
| 10 | Leaky-bucket congestion control | `lab7.java` | Java |

## Requirements

- Experiments 01-03 require NS2. Experiment 03 also uses NAM for animation, GNU AWK to extract congestion-window values, and `xgraph` to plot them.
- Experiments 04, 06-10 require a JDK (Java 8 or later).
- Experiment 05 requires a C compiler such as GCC or Clang.

Run each command from its experiment folder. The `.java` public class names match their filenames.

## Run instructions

### Experiment 01: Three-node point-to-point network

```sh
cd Experiment-01
ns prog1.tcl
```

The script writes `prog1.tr` and `prog1.nam`, then prints the drop count. Change `linkBandwidth` or `queueSize` near the top of `prog1.tcl` to compare runs. The manual’s example configuration reports 8 drops; the count can vary with NS2 versions and parameter changes.

### Experiment 02: Ping and traceroute-style probes

```sh
cd Experiment-02
ns ping_traceroute.tcl
```

The script probes nodes 1 through 5 in order from node 0 and also sends end-to-end pings. It creates congestion on the node 2-to-node 3 link and reports dropped pings and total drops. NS2 `Agent/Ping` does not implement TTL-based operating-system traceroute; this lab demonstrates the route as sequential hop probes.

### Experiment 03: Ethernet LAN and congestion windows

```sh
cd Experiment-03
ns ethernet_lan.tcl
awk -f cwnd.awk cwnd1.tr > source1.dat
awk -f cwnd.awk cwnd2.tr > source2.dat
xgraph source1.dat source2.dat
```

The two series compare TCP Vegas (node 1 to node 7) and TCP Reno (node 2 to node 8). The `.tr`, `.nam`, and `cwnd*.tr` files are generated by NS2.

### Experiment 04: CRC-CCITT

```sh
cd Experiment-04
javac CRC1.java
java CRC1
```

Sample session (the message is `1101011011`; press Enter at the received-codeword prompt):

```text
Enter message bits: 1101011011
Generator (CRC-CCITT): 10001000000100001
Checksum (16 bits): 1011111011001101
Transmitted codeword: 11010110111011111011001101
Enter received codeword (Enter to verify the generated one):
Data stream is valid.
```

To demonstrate an error, enter a codeword with any one bit changed; it should be reported invalid. The implementation follows the manual’s modulo-2 long division, using polynomial `0x1021` and a zero initial remainder.

### Experiment 05: Sliding window

```sh
cd Experiment-05
gcc -std=c11 -Wall -Wextra -o SlidingWindow SlidingWindow.c
./SlidingWindow
```

Sample input: window size `3`, frame count `5`, frames `10 20 30 40 50`. The program displays batches `10 20 30` and `40 50`, with an acknowledgement after each batch.

### Experiment 06: Bellman-Ford and path vectors

```sh
cd Experiment-06
javac ford.java
java ford
```

Enter the vertex count, an adjacency matrix, and a source vertex. As in the manual, `0` means no edge outside the diagonal; negative edge weights are allowed. For the manual’s five-vertex sample matrix and source `1`, distances are `0, 3, 5, 2, 5`, with routes shown as path vectors. The program reports unreachable vertices and reachable negative-weight cycles.

### Experiment 07: TCP file transfer

```sh
cd Experiment-07
javac server1.java client1.java
mkdir shared_files
```

Put a UTF-8 text file such as `hello.txt` inside `shared_files`. In one terminal start the server with `java server1`; in another run `java client1 hello.txt` (or run `java client1` to be prompted). The server listens on `127.0.0.1:4000` and serves only files inside `shared_files`.

### Experiment 08: UDP communication

```sh
cd Experiment-08
javac UDPServer.java UDPClient.java
```

Start `java UDPServer` in one terminal and `java UDPClient` in another. For input `hello network`, the client receives `HELLO NETWORK`. Send `quit` to stop the server.

### Experiment 09: RSA

```sh
cd Experiment-09
javac RSA.java
java RSA
```

Sample: enter `Computer Networks`; after displaying generated public parameters and encrypted byte values, the program prints `Decrypted text: Computer Networks`. This small textbook-RSA program is for demonstrating modular exponentiation, not for protecting real data.

### Experiment 10: Leaky bucket

```sh
cd Experiment-10
javac lab7.java
java lab7
```

Sample input: 5 intervals with arrivals `3 4 1 5 0`. With capacity 4 and leak rate 3, the program accepts the first three bursts, drops the burst of 5, and prints the sent and remaining queue at each interval.

## Validation status

All eight Java source files compiled with the installed Java 8 JDK. Sample runs passed for CRC generation and validation, Bellman-Ford routes, RSA round-trip, and leaky-bucket output. The TCP file transfer and UDP request/reply programs also passed local client-server checks. The AWK extractor passed a sample congestion-window trace using the AWK executable bundled with Git for Windows.

This environment has no C compiler, NS2, NAM, or `xgraph`, so `SlidingWindow.c` could not be compiled and the Tcl simulations could not be run here. Install the missing tools to run those experiments as described above.
